# Tencent Weiyun

The `weiyun` backend accesses [Tencent Weiyun](https://www.weiyun.com/). It can
also be selected with the type name `tencentweiyun`.

Paths are specified as `remote:path`, and may be as deep as required, e.g.
`remote:directory/subdirectory`.

## Configuration

Run `rclone config` and choose `weiyun`, then paste the cookies of a logged-in
browser session (they must contain `uin`, `skey` and `p_skey`).

```ini
[myweiyun]
type = weiyun
cookies = uin=...; skey=...; p_skey=...
```

### Hashes

SHA1 is supported.

### Uploads

Weiyun asks for parts of the file at arbitrary offsets, so files up to 1 MiB
are buffered in memory and larger files are copied to a temporary file first.
If the server already has the content the upload completes without
transferring data.

### Modification times

Modification times are not supported; the server's time is shown.

### Standard options

Here are the Standard options specific to weiyun (Tencent Weiyun).

#### --weiyun-cookies

Weiyun Cookies (must include uin and skey or p_skey)

Properties:

- Config:      cookies
- Env Var:     RCLONE_WEIYUN_COOKIES
- Type:        string
- Required:    true

### Advanced options

Here are the Advanced options specific to weiyun (Tencent Weiyun).

#### --weiyun-root-folder-id

Root folder ID (defaults to user root directory)

Properties:

- Config:      root_folder_id
- Env Var:     RCLONE_WEIYUN_ROOT_FOLDER_ID
- Type:        string
- Required:    false

## Limitations

- Larger uploads need temporary disk space equal to the file size.
- Modification times can't be set.
- Not available on plan9.
