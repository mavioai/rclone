# Quark Drive / UC Drive

The `quark` backend accesses [Quark Drive](https://pan.quark.cn/) and UC Drive.
It can also be selected with the type names `quarkdrive` and `ucdrive`.

Paths are specified as `remote:path`, and may be as deep as required, e.g.
`remote:directory/subdirectory`.

## Configuration

Run `rclone config` and choose `quark`. Paste the cookie of a logged-in browser
session (it must contain `__puus`) and choose `mode = quark` or `mode = uc`.
Refreshed cookie values returned by the server are saved back to the config.

```ini
[myquark]
type = quark
mode = quark
cookie = __puus=...; b-user-id=...
```

### Uploads and rapid upload

Quark needs the MD5 and SHA1 of the file before an upload starts. When the
source provides both the data is streamed in parts of the size the server
chooses, each part retried; otherwise the input is first copied to a temporary
file while hashing. If the server already has the content the file is created
without transferring data.

### Hashes and modification times

No hashes are reported for remote files. Modification times are not supported;
the upload time is shown.

### Standard options

Here are the Standard options specific to quark (Quark Drive / UC Drive).

#### --quark-cookie

Quark or UC Cookie (must include __puus)

The session cookie __puus is refreshed by the server from time to time
and the refreshed value is written back to the config file.

Properties:

- Config:      cookie
- Env Var:     RCLONE_QUARK_COOKIE
- Type:        string
- Required:    true

#### --quark-mode

Service mode: quark (Quark Drive) or uc (UC Drive)

Properties:

- Config:      mode
- Env Var:     RCLONE_QUARK_MODE
- Type:        string
- Default:     "quark"
- Examples:
  - "quark"
    - Quark Drive
  - "uc"
    - UC Drive

### Advanced options

Here are the Advanced options specific to quark (Quark Drive / UC Drive).

#### --quark-root-folder-id

Root folder ID

Properties:

- Config:      root_folder_id
- Env Var:     RCLONE_QUARK_ROOT_FOLDER_ID
- Type:        string
- Default:     "0"

#### --quark-encoding

The encoding for the backend.

Properties:

- Config:      encoding
- Env Var:     RCLONE_QUARK_ENCODING
- Type:        Encoding
- Default:     Slash,InvalidUtf8,Dot

#### --quark-description

Description of the remote.

Properties:

- Config:      description
- Env Var:     RCLONE_QUARK_DESCRIPTION
- Type:        string
- Required:    false

## Limitations

- No hashes, so `rclone check` compares sizes only.
- Modification times can't be set.
