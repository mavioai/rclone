# 115 Cloud

The `cloud115` backend accesses [115 Cloud](https://115.com/). It can also be
selected with the type names `115` and `115drive`.

Paths are specified as `remote:path`, and may be as deep as required, e.g.
`remote:directory/subdirectory`.

## Configuration

Run `rclone config` and choose `cloud115`. You can either paste the cookie
of a logged-in session (`UID=...; CID=...; SEID=...; KID=...`) or leave it
empty and log in by scanning the QR code shown in the terminal with the 115
app. After a QR login the cookie is stored in the config and the one-time
`qrcode_token` is cleared.

`qrcode_source` selects the device type the session is created for (default
`tv`). 115 allows one session per device type, so logging in signs out any
other session of the same type.

```ini
[my115]
type = cloud115
cookie = UID=...; CID=...; SEID=...; KID=...
```

### Hashes

SHA1 is supported, so `rclone check` and `--checksum` work.

### Uploads and rapid upload

115 needs the SHA1 of the whole file and of its first 128 KiB before an upload
starts, and may ask for the SHA1 of a range it chooses. If the source provides
SHA1 and can be read by range, rclone streams the file; otherwise it first
copies it to a temporary file while hashing. If 115 already has the content the
file is created without transferring data. Files up to `chunk_size` are sent to
Aliyun OSS in one request, larger files as a multipart upload; every part is
retried.

### Offline downloads

`rclone backend addurl remote:dir URL` adds an offline download task (HTTP,
magnet, ed2k). `tasks` lists tasks, `deltask` deletes one and `cleartasks`
clears them. The same operations are available through the rc as
`operations/addurl`, `operations/listoffline` and `operations/deleteoffline`.

### Modification times

Modification times are not supported; the server's update time is shown.

### Standard options

Here are the Standard options specific to cloud115 (115 Cloud / 115 Drive).

#### --cloud115-cookie

115 Cookie (UID=...; CID=...; SEID=...; KID=...).

Leave blank to log in by scanning a QR code with the 115 app
during "rclone config".

Properties:

- Config:      cookie
- Env Var:     RCLONE_CLOUD115_COOKIE
- Type:        string
- Required:    false

### Advanced options

Here are the Advanced options specific to cloud115 (115 Cloud / 115 Drive).

#### --cloud115-qrcode-token

UID of a QR code login session confirmed in the 115 app.

It is exchanged for a cookie on first use and then cleared.

Properties:

- Config:      qrcode_token
- Env Var:     RCLONE_CLOUD115_QRCODE_TOKEN
- Type:        string
- Required:    false

#### --cloud115-qrcode-source

Client device type to log in as with a QR code.

Logging in as a device type signs out other sessions of the same type.

Properties:

- Config:      qrcode_source
- Env Var:     RCLONE_CLOUD115_QRCODE_SOURCE
- Type:        string
- Default:     "tv"
- Examples:
  - "tv"
    - Smart TV client
  - "web"
    - Web browser client
  - "android"
    - Android app client
  - "ios"
    - iOS app client
  - "alipaymini"
    - Alipay Mini Program
  - "wechatmini"
    - WeChat Mini Program
  - "qandroid"
    - QAndroid client

#### --cloud115-root-folder-id

Root folder ID

Properties:

- Config:      root_folder_id
- Env Var:     RCLONE_CLOUD115_ROOT_FOLDER_ID
- Type:        string
- Default:     "0"

#### --cloud115-chunk-size

Upload chunk size.

Files up to this size are uploaded in a single request, larger files
in parts of this size (raised automatically to stay within 10,000
parts). Each transfer buffers one chunk in memory.

Properties:

- Config:      chunk_size
- Env Var:     RCLONE_CLOUD115_CHUNK_SIZE
- Type:        SizeSuffix
- Default:     16Mi

#### --cloud115-encoding

The encoding for the backend.

See the [encoding section in the overview](/overview/#encoding) for more info.

Properties:

- Config:      encoding
- Env Var:     RCLONE_CLOUD115_ENCODING
- Type:        Encoding
- Default:     Slash,LtGt,DoubleQuote,Colon,Question,Asterisk,Pipe,BackSlash,Ctl,LeftSpace,RightSpace,InvalidUtf8,Dot

#### --cloud115-description

Description of the remote.

Properties:

- Config:      description
- Env Var:     RCLONE_CLOUD115_DESCRIPTION
- Type:        string
- Required:    false

## Backend commands

Here are the commands specific to the cloud115 backend.

Run them with:

```console
rclone backend COMMAND remote:
```

The help below will explain what arguments each command takes.

See the [backend](/commands/rclone_backend/) command for more
info on how to pass options and arguments.

These can be run on a running backend using the rc command
[backend/command](/rc/#backend-command).

### rapid-upload

Create a file from its hashes without uploading data.

```console
rclone backend rapid-upload remote: [options] [<arguments>+]
```

This command asks 115 to create a file from content it already
stores, identified by size and SHA1. It is also available as
"rapidupload".

Usage examples:

```console
rclone backend rapid-upload cloud115:dir "115://name|size|sha1|block_sha1"
rclone backend rapid-upload cloud115:dir name size sha1 [block_sha1]
rclone backend rapid-upload cloud115:dir -o name=file.mkv -o size=1048576 -o sha1=...
```

block_sha1 is the SHA1 of the first 128 KiB. If 115 asks for a proof of
a range of the content the command fails, since there is no data to
read it from.

Options:

- "block_sha1": SHA1 of the first 128 KiB.
- "name": File name.
- "path": Directory to create the file in, relative to the remote.
- "sha1": SHA1 of the whole file.
- "size": File size in bytes.

### addurl

Add an offline download task for a url.

```console
rclone backend addurl remote: [options] [<arguments>+]
```

This command adds an offline (cloud-side) download task for a url
(http, magnet or ed2k). It is also available as "offline".

Usage examples:

```console
rclone backend addurl cloud115:dirpath url
```

Downloads are stored in 'dirpath', which must exist.

Options:

- "path": Directory to download into, relative to the remote.

### tasks

List offline download tasks.

```console
rclone backend tasks remote: [options] [<arguments>+]
```

This command lists the offline download tasks. It is also
available as "listoffline".

```console
rclone backend tasks cloud115:
```

### deltask

Delete an offline download task.

```console
rclone backend deltask remote: [options] [<arguments>+]
```

This command deletes the offline download task with the given
info hash. It is also available as "deleteoffline". Downloaded files
are kept.

```console
rclone backend deltask cloud115: hash
```

### cleartasks

Clear finished offline download tasks.

```console
rclone backend cleartasks remote: [options] [<arguments>+]
```

This command clears the finished offline download tasks.

```console
rclone backend cleartasks cloud115:
```

## Limitations

- Modification times can't be set.
- Logging in with QR code signs out other sessions of the same device type.
