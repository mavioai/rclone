# Aliyun Drive

The `aliyundrive` backend accesses [Aliyun Drive](https://www.alipan.com/)
through the Aliyun Drive Open Platform API. It can also be selected with the
type names `aliyun` and `alibabadrive`.

Paths are specified as `remote:path`, and may be as deep as required, e.g.
`remote:directory/subdirectory`.

## Configuration

Run `rclone config` and choose `aliyundrive`, then enter a refresh token.

By default (`use_online_api = true`) the access token is renewed through the
service at `oauth_token_url`, a third-party service run by the OpenList
community (`https://api.oplist.org/alicloud/renewapi`). This is needed for
refresh tokens obtained from its QR code tool, because they belong to that
service's application. **Your refresh token is sent to that service.** Set
`alipan_type = alipanTV` for tokens obtained with the TV login.

If you have your own Open Platform application, set `client_id`,
`client_secret` and `use_online_api = false`; tokens are then renewed only with
`openapi.alipan.com`.

```ini
[myaliyun]
type = aliyundrive
refresh_token = ...
```

### Hashes

SHA1 is supported.

### Uploads and rapid upload

Uploads are streamed in `chunk_size` parts with one part in memory; each part
is retried and its upload URL refreshed when it expires. With `rapid_upload`
enabled, files over 100 KiB are first offered to the server by SHA1 and a
proof code read from a range of the source, so content the server already has
is not transferred.

### Modification times

The modification time is sent as `local_modified_at` with millisecond
precision.

### Standard options

Here are the Standard options specific to aliyundrive (Aliyun Drive Open Platform API).

#### --aliyundrive-refresh-token

Refresh Token obtained from Aliyun Drive Open Platform.

Properties:

- Config:      refresh_token
- Env Var:     RCLONE_ALIYUNDRIVE_REFRESH_TOKEN
- Type:        string
- Required:    true

#### --aliyundrive-use-online-api

Refresh the access token with the online API at oauth_token_url.

When this is set (the default) the refresh token is sent to
oauth_token_url, which by default is a third-party service run by the
OpenList community (api.oplist.org), not by Aliyun. That service
holds the Open Platform app credentials and returns new tokens.

If you have registered your own Aliyun Drive Open Platform app, set
client_id and client_secret and turn this off: rclone then refreshes
tokens directly with openapi.alipan.com and no token is sent to anyone
but Aliyun.

Properties:

- Config:      use_online_api
- Env Var:     RCLONE_ALIYUNDRIVE_USE_ONLINE_API
- Type:        bool
- Default:     true

#### --aliyundrive-drive-type

Drive type to access: resource, backup, or default.

Properties:

- Config:      drive_type
- Env Var:     RCLONE_ALIYUNDRIVE_DRIVE_TYPE
- Type:        string
- Default:     "resource"
- Examples:
  - "resource"
    - Resource drive (Default / Recommended)
  - "backup"
    - Backup drive
  - "default"
    - Default drive

#### --aliyundrive-remove-way

Delete action behavior: trash (move to recycle bin) or delete (permanently delete).

Properties:

- Config:      remove_way
- Env Var:     RCLONE_ALIYUNDRIVE_REMOVE_WAY
- Type:        string
- Default:     "trash"
- Examples:
  - "trash"
    - Move file to recycle bin
  - "delete"
    - Delete file permanently

### Advanced options

Here are the Advanced options specific to aliyundrive (Aliyun Drive Open Platform API).

#### --aliyundrive-alipan-type

Type of the refresh token when using the online API.

Properties:

- Config:      alipan_type
- Env Var:     RCLONE_ALIYUNDRIVE_ALIPAN_TYPE
- Type:        string
- Default:     "default"
- Examples:
  - "default"
    - Token from the Aliyun Drive QR code login (driver_txt=alicloud_qr)
  - "alipanTV"
    - Token from the Aliyun Drive TV login (driver_txt=alicloud_tv)

#### --aliyundrive-oauth-token-url

URL of the online token refresh API.

Only used when use_online_api is set. The refresh token is sent to this
URL. The default is run by the OpenList community, not by Aliyun.

Properties:

- Config:      oauth_token_url
- Env Var:     RCLONE_ALIYUNDRIVE_OAUTH_TOKEN_URL
- Type:        string
- Default:     "https://api.oplist.org/alicloud/renewapi"

#### --aliyundrive-client-id

OAuth Client ID of your own Aliyun Drive Open Platform app.

Required when use_online_api is off. Leave empty to use the online API.

Properties:

- Config:      client_id
- Env Var:     RCLONE_ALIYUNDRIVE_CLIENT_ID
- Type:        string
- Required:    false

#### --aliyundrive-client-secret

OAuth Client Secret of your own Aliyun Drive Open Platform app.

Required when use_online_api is off. Leave empty to use the online API.

Properties:

- Config:      client_secret
- Env Var:     RCLONE_ALIYUNDRIVE_CLIENT_SECRET
- Type:        string
- Required:    false

#### --aliyundrive-drive-id

Specific drive ID (leave empty to discover automatically based on drive_type).

Properties:

- Config:      drive_id
- Env Var:     RCLONE_ALIYUNDRIVE_DRIVE_ID
- Type:        string
- Required:    false

#### --aliyundrive-root-folder-id

Root folder ID to start in (default is 'root').

Properties:

- Config:      root_folder_id
- Env Var:     RCLONE_ALIYUNDRIVE_ROOT_FOLDER_ID
- Type:        string
- Default:     "root"

#### --aliyundrive-rapid-upload

Attempt rapid upload before chunked uploading if content hash matches.

If the source has no SHA1 hash, the first 1 KiB is sent as a pre-hash
and, only if the server knows a matching file, the upload is spooled
to a temporary file to compute the full SHA1.

Properties:

- Config:      rapid_upload
- Env Var:     RCLONE_ALIYUNDRIVE_RAPID_UPLOAD
- Type:        bool
- Default:     false

#### --aliyundrive-chunk-size

Chunk size for multipart upload (minimum 100k, maximum 5G).

Properties:

- Config:      chunk_size
- Env Var:     RCLONE_ALIYUNDRIVE_CHUNK_SIZE
- Type:        SizeSuffix
- Default:     20Mi

#### --aliyundrive-encoding

The encoding for the backend.

See the [encoding section in the overview](/overview/#encoding) for more info.

Properties:

- Config:      encoding
- Env Var:     RCLONE_ALIYUNDRIVE_ENCODING
- Type:        Encoding
- Default:     Slash,InvalidUtf8,Dot

#### --aliyundrive-description

Description of the remote.

Properties:

- Config:      description
- Env Var:     RCLONE_ALIYUNDRIVE_DESCRIPTION
- Type:        string
- Required:    false

## Limitations

- With `use_online_api = true` the refresh token is sent to a third-party service.
- Files can't be copied or moved between different drives.
