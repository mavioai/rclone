# Baidu Netdisk

The `baidunetdisk` backend accesses [Baidu Netdisk](https://pan.baidu.com/)
through its open platform API. It can also be selected with the type name
`baidudrive`.

Paths are specified as `remote:path`, and may be as deep as required, e.g.
`remote:directory/subdirectory`.

## Configuration

Run `rclone config` and choose `baidunetdisk`, then enter an OAuth refresh
token. A built-in client ID is used unless you supply your own `client_id` and
`client_secret`. The rotated refresh token is saved back to the config.

```ini
[mybaidu]
type = baidunetdisk
refresh_token = ...
```

### Hashes

MD5 is supported.

### Uploads and rapid upload

Baidu needs the MD5 of every block before an upload starts, so the data is read
twice: a local source is opened a second time for hashing and then streamed,
any other source is copied to a temporary file while hashing. Only one block is
held in memory. The block size follows the account level: 4 MiB for normal
accounts, 16 MiB for VIP and 32 MiB for SVIP, up to 2048 blocks. If Baidu
already has the content the file is created without transferring data.
`rclone backend rapid-upload` accepts `md5#slicemd5#size#name` links.

### Download modes

`download_api = official` uses the official download links. `crack` uses DLNA
links with the user agent from `custom_crack_ua`.

### Modification times

The source modification time is sent on upload, but it can't be changed
afterwards, so rclone treats modification times as unsupported.

### Standard options

Here are the Standard options specific to baidunetdisk (Baidu Netdisk).

#### --baidunetdisk-refresh-token

OAuth Refresh Token

Properties:

- Config:      refresh_token
- Env Var:     RCLONE_BAIDUNETDISK_REFRESH_TOKEN
- Type:        string
- Required:    true

#### --baidunetdisk-download-api

Download API method to use (official or crack)

Properties:

- Config:      download_api
- Env Var:     RCLONE_BAIDUNETDISK_DOWNLOAD_API
- Type:        string
- Default:     "official"
- Examples:
  - "official"
    - Official open API (uses dlink with pan.baidu.com UA)
  - "crack"
    - DLNA crack API (bypasses speed throttle on some accounts)

### rapid-upload

Create a file from its hashes without uploading data.

```console
rclone backend rapid-upload remote: [options] [<arguments>+]
```

This command asks Baidu Netdisk to create a file from content it
already stores. It is also available as "rapidupload".

Usage examples:

```console
rclone backend rapid-upload baidunetdisk:dir "md5#slicemd5#size#name"
rclone backend rapid-upload baidunetdisk:dir name size md5 slice_md5
```

slice_md5 is the MD5 of the first 256 KiB.

Options:

- "md5": MD5 of the whole file.
- "name": File name.
- "path": Directory to create the file in, relative to the remote.
- "size": File size in bytes.
- "slice_md5": MD5 of the first 256 KiB.

## Limitations

- Empty files can't be uploaded.
- Modification times can't be set.
- Files are limited to 2048 blocks (8 GiB for normal accounts).
